# Legacy replay engine v1

Exact engine sources from main commit `989927ba57dde781a4a856eaa2bbb6a1d01afb4b`.
AGPL-3.0-only, as the rest of OpenMahjong. Used only for persisted version-1 games,
so historical logs keep their original rules behavior, including known defects.
New games must use the current engine. Do not fix or format these files: changing
them changes historical outcomes. Compatibility fixtures protect this boundary.
