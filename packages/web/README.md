# @openmahjong/web

The Open Mahjong web client, per brief §7–§10: land-and-play home, a flat
straight-down table (portrait-first, dark theme default), traditional tile
faces drawn clean, the full §9 animation set as one motion language, and
tile-click sound only. Offline-capable PWA; anonymous play with settings
and history in local storage only (brief §11).

**Status: placeholder.** Per the brief's rendering gate (§3, §8), no UI
surface is built before a faithful rendering passes independent QC and
Michael's approval. The client renders `@openmahjong/engine` state and
holds no game logic of its own — if client and engine disagree, the
engine is right by definition.
